# Справочники от 28 октября 2026

Статус: реализовано, локальные проверки пройдены. Пользователь подтвердил
публикацию веба и выпуск Android APK после подключения норм времени.

## Данные и цены

- `Строительные_цены_по_городам_2026-10-28_1.xlsx`: для каждой из 16 операций
  рассчитано простое среднее по всем 16 городам. Работа и материалы отдельно:
  32 строки `average.*`. Каждый город имеет одинаковый вес; округление до копейки
  HALF_UP после усреднения. Это средние нормативные ориентиры из файла, не
  статистическая оценка рыночных предложений. Выбора города нет ни в форме, ни в API.
- `Mobilny_prorab_svodny_spravochnik.xlsx`: 308 материалов и 135 работ `ref.*`.
  Исходные цены, единицы закупки, статусы и источники сохранены. Указанная в файле
  оценочная цена не превращается в проверенную после импорта.
- Дополнительно `rule.stretch.minimum`: минимум заказа натяжных потолков 12000 ₽
  из листа «Пояснения», применяется один раз на проект.
- Flyway V13 добавляет 476 строк, не меняя десять существовавших ставок и проекты.
  Всего при полном справочнике 486 строк. Отметка проверки новых строк — false.
- Скрипт `scripts/import_price_workbooks.py` воспроизводит ресурс
  `backend/src/main/resources/pricing/import-2026-10-28.json` из двух файлов.
  После публикации V13 ресурс фиксируется: последующие изменения цен через админку
  или новую миграцию, не редактированием уже применённого импорта.

## Что использует калькулятор catalog-pricing-5

| Расчёт | Источник |
|---|---|
| Ламинат, паркетная доска, плитка, обои, окраска | Средняя ставка работы + средняя стоимость материалов на м² |
| Подготовка стен и пола | Средние ставки штукатурки / стяжки; прежние правила включения и частичного объёма |
| Демонтаж | Отдельные работы сводного справочника; без данных о старой отделке — обои, ламинат, натяжной потолок |
| SPC, декоративная штукатурка | Материалы выбранного класса с нормами расхода + отдельная работа |
| Натяжной потолок | Полотно + комплекс монтажа по периметру + вставка; минимум заказа один раз |
| ГКЛ-потолок | Листы, каркас, крепёж, швы по нормам сводного файла + монтаж + средняя окраска |
| Двери | Комплект выбранного класса + отдельный монтаж |
| Стандартная кухня | Комплект 3 м выбранного класса пропорционально длине, с шагом продажи 0,01 комплекта + сборка за пог. м |
| Панель, духовка, холодильник, вытяжка, посудомойка | Цена конкретной роли по классу + оценочная доля 1/6 общего подключения шести приборов |

Материалы городской операции считаются одним агрегатом. Например, ламинат уже
включает подложку: добавлять `F_underlay_lam` нельзя. Полная стоимость отдельного
товара из другого справочника поверх агрегата тоже не добавляется.

Бизнес = Премиум. Для комплектов и товаров с отдельной ценой по классу коэффициент
класса равен 1. Для средних городских материалов без классов остаются оценочные
1 / 1,3 / 1,7; труд этими коэффициентами не умножается. Подготовка по классу не
удорожается. Это правило модели, а не вывод из городской выборки.

Пакетные материалы SPC / декоративной отделки / ГКЛ объединяются по одному ID
по всему проекту до округления вверх. Оплата целых упаковок распределяется между
разделами по накопленной потребности; остаток первой упаковки используется дальше.
Это распределение закупки, не точная стоимость расхода материала в каждом помещении.

## Что не подменено новым файлом

Геометрия и доли частичных работ сохранены. Нормативная часть срока подключена
из `Сроки.xlsx`: [TIME_NORMS.md](TIME_NORMS.md). По электрике, сантехнике,
остеклению, утеплению, отдельной плите и мебели остаются прежние укрупнённые ставки.
Для явно выбранных нестандартных фасадов/каменной столешницы сохраняется прежняя
оценка, включающая монтаж: новый стандартный комплект не добавляется поверх неё.
В данных нет полной сопоставимой цены этих вариантов для имеющихся полей ввода.

Наличие всех 443 строк в БД не означает реализацию 376 правил нового Excel.
Новые режимы из него (например, всегда новые подключения) не заменяют явные отказы
пользователя. Балконы сохраняются. СВЧ, новые параметры обмеров и новые этапы не
добавлены автоматически. Пример «64 м²» — пример другой модели; совпадение итогов
с ним не заявляется. Доставка, мусор, дополнительные доборы, отделка скрытой двери,
световые узлы потолка и другие неописанные текущими полями детали не выдумываются.
Комплекс монтажа потолка включён в категорию работ/услуг вместе с его материалами:
точной разбивки поставщика нет. Эти ограничения указаны в детализации.

## Админка и сохранность

`/porabadmin`: поиск, фильтры средних ставок / сводного справочника / прежних ставок,
источник раскрывается отдельно. Цена и доли редактируются; удаление подтверждается.
Конфликт версии сохраняет ввод. Можно восстановить любую импортированную строку,
указав цену вручную. Если нужная ставка удалена, расчёт завершается ошибкой, а не
заменяется скрытой ценой. Удаление неиспользуемой позиции не блокирует другой расчёт.
Нормы, фасовки и соответствия полям пока задаются версионированными данными/кодом,
не формой изменения цены.

Смета хранит использованные цены и количества. Старые снимки не переписываются.
Для существующего проекта: «Уточнить параметры» → «Пересчитать по текущим ценам» →
«Применить расчёт». Финансовый план обновляется отдельно существующей командой,
расходы и фактический график сохраняются. Новые коды подготовки и демонтажа учтены
при построении прежних фаз графика.
