# Стиль интерфейса — 20 октября 2026

Общий стиль веба и Expo: тёплый фон, шалфейный акцент, пастельные поверхности,
контрастный текст. Без внешних шрифтов, новых библиотек и изменений бизнес-логики.

| Роль | Цвет |
|---|---|
| Фон | #f5f5f0 |
| Поверхность | #fffefa |
| Основной текст | #263c35 |
| Вторичный текст | #5e6e65 |
| Основная кнопка | #365c4c |
| Шалфей | #e6eee3 |
| Лаванда | #eeebf5 |
| Песочный | #f4ecdf |

Веб: переменные и компоненты в `frontend/css/app.css`.
Expo: `palette`, `styles`, `Grid`, `Metric` в `mobile/src/components/ui.tsx`.

- Контент до 920 px в вебе, 880 px в Expo; поля мастера в вебе до 760 px.
- Основные отступы 8/12/16/20/24/32 px; радиусы 14/16/20/22 px.
- Две колонки для выбора и проектов на широком экране, одна на телефоне.
  Длинные формы уточнения сгруппированы в сетку. Expo учитывает увеличенный системный шрифт.
- Поля от 56 px, основные кнопки от 52 px, вспомогательные от 44–48 px.
- Выбор обозначен цветом, границей и отметкой; disabled визуально отличается.
- Видимый клавиатурный фокус в вебе, reduced-motion отключает переходы.
- Бюджет и срок — отдельные цветовые карточки. Статус/уточнение сохраняются под сроком.
- Таблицы сметы прокручиваются внутри своего блока, а не растягивают всю страницу.

Ориентиры: [WCAG — контраст текста](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html),
[WCAG — размер цели](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html).
Для выбранных пар измерены отношения контраста: основной текст/поверхность 11,69:1,
вторичный текст/песочный 4,60:1, вторичный текст/лаванда 4,58:1,
placeholder/поверхность 4,73:1, текст основной кнопки/фон 7,45:1.
Это проверка конкретных цветов, не заявление о полном соответствии приложения WCAG.

Проверки: 14 web-unit, mobile typecheck/lint, 22 веб-браузерных сценария
(20 первым запуском, 2 auth после исправления старого неоднозначного селектора),
4 мобильных сценария. Скриншоты и отсутствие переполнения проверены на
320/390/768/1440 px. Expo проверен через браузер, не через новую нативную сборку.
Превью: `frontend/build/design/` (локальные артефакты, не в Git).
