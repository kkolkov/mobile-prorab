# Цены и сроки: короткая инструкция

Актуально для catalog-pricing-8, 29.10.2026.
Полная инструкция с формулами и расположением кода: [OPERATING_MANUAL.md](OPERATING_MANUAL.md).

## Как связаны части приложения

Данные квартиры → код определяет состав и объёмы → берёт цены из БД →
применяет нужные коэффициенты → сохраняет смету → обновляет план по действию пользователя.

Админка цен: https://mobile-prorab.onrender.com/porabadmin
Коэффициенты: /porabadmin/coefficients.html (после публикации этой версии).
Нормы времени: https://mobile-prorab.onrender.com/porabadmin/time-norms.html

Excel нужен для подготовки данных. Изменение Excel не обновляет рабочую базу.
Локальная админка и Render меняют разные базы. Сейчас админка публичная, без авторизации.

## Что менять без программирования

| Задача | Где |
|---|---|
| Стоимость материала | Его строка в админке цен |
| Цена работы | Отдельная строка работы |
| Норма времени | Админка времени, человеко-часы на 100 м² |
| Распределение суммы между черновыми, чистовыми и работами | Доли строки цены |
| Минимальная стоимость заказа потолков | rule.stretch.minimum |
| Класс материалов, доля стен/частичных работ, границы бюджета и резерв | Админка → Коэффициенты расчёта |
| Формулы площадей/трасс, нормы расхода, бригада и паузы | Код, нужен разработчик |
| Норма расхода/размер упаковки/запас | Метаданные в кодовой поставке, нужен разработчик |

## Пример: пол комнаты 20 м², класс «Комфорт»

Начальные ставки ламината: работа 1090 ₽/м², материалы 1516,88 ₽/м².
Работа: round(20 × 1090) = 21 800 ₽.
Материалы: round(20 × 1516,88 × 1,3) = 39 439 ₽.
Пол: 61 239 ₽. Подготовка пола, демонтаж и другие работы считаются отдельно.

Плитка использует собственные цены tile_floor, а не старый множитель ×1,6 к ламинату.
Готовые классовые комплекты и прайсы СПб не умножаются на класс повторно.

## Как изменить цену

1. Найдите нужный код и проверьте единицу. Цена за упаковку — не цена за м².
2. Сохраните прежние значения для возможного возврата.
3. Нажмите «Изменить». В average.work — только работа, в average.material — только материалы.
4. Для комплексной услуги учитывайте включённый монтаж один раз.
5. Укажите доли категорий. Черновые + работа + остаток чистовых = 100%.
   Доли делят сумму, а не увеличивают её. Для импортированных ref-материалов
   начальная черновая доля равна нулю; при необходимости классификацию нужно уточнить.
6. Запишите источник, дату, состав, оговорки «от» и включение доставки/монтажа.
7. Поставьте отметку проверки после сверки и сохраните. Галочка не меняет сумму.
8. Пересчитайте контрольный проект и сравните конкретные строки.

Нельзя заменить цену части комплекта полной ценой: ref.K_cabinets — цена 0,01
трёхметрового комплекта. Для 3 м калькулятор покупает 100 таких единиц.
Нельзя менять норму времени на срок всей квартиры: единица — чел.-ч / 100 м² операции.

Удаление используемой строки остановит расчёт, которому она нужна. Неиспользуемые
справочные строки на него не влияют. Старые сметы сохранятся. Для восстановления
нажмите «Вернуть» и заполните данные. Новый произвольный код требует поддержки в коде.

## Как обновить существующий проект

1. Открыть «Уточнить параметры проекта».
2. Нажать «Пересчитать по текущим ценам» и дождаться результата.
3. Сравнить сметы и применить расчёт.
4. В финансовом трекере отдельно обновить план из сметы.

Фактические расходы останутся. Начатый график сам не перестроится.
Повышение цены не увеличивает нормативные часы. Если надо изменить срок,
нужны нормы времени/состав работ, а не завышение стоимости.

## Бюджет и срок

Стоимость = сумма строк. Минимум = стоимость × 0,90, максимум = ×1,15.
Бюджет с резервом = округлённый максимум ×1,10, с округлением до рубля.
При стоимости 1 млн ₽: 900 тыс. — 1,15 млн; с резервом 1,265 млн.

Часы = объём × норма / 100. Для двух человек по 8 часов дни этапа =
ceil(часы / 16 × 7/5). Часть работ пока не имеет норм и использует ориентир этапа;
при подготовке добавляется условная пауза 8 дней. Верхний срок = ceil(нижний ×1,2).

## Что делать при расхождении

- Неверная цена единицы — править справочник.
- Неверные м²/количество — уточнять обмеры и формулу объёма.
- Лишняя работа — проверять выбор и правило включения.
- Не те категории финансов — проверять доли.
- Старая сумма в проекте — проверить пересчёт, применение и обновление плана.

Не подгоняйте одну общую ставку, чтобы скрыть ошибку в количестве.
Камень пока не добавляется поверх кухни с постформингом: нужна цена гарнитура
без обычной столешницы или подтверждённый вычет. Подробности: SPB_PRICES.md.

## Как менять коэффициент

1. Откройте «Коэффициенты расчёта», прочитайте описание и нажмите «Изменить».
2. Введите множитель: 1,3 = +30%; 0,5 = половина объёма. Для доли стен 0,85 означает 15% проёмов.
3. Нажмите «Сохранить». Пределы указаны рядом с полем; значения вне диапазона сервер отклонит.
4. Пересчитайте смету проекта, сравните и примените её. Старые оценки и расходы автоматически не меняются.

При конфликте двух вкладок сначала сверьте текущее значение из базы со своим вводом.
В базе это calculation_coefficients; начальные значения добавляет V18. Коэффициенты не удаляются: каждый нужен формуле. Все 12 значений сохранены в пояснениях каждой новой сметы. Отдельные классовые комплекты и прямые ставки работ не умножаются на коэффициент класса повторно.
