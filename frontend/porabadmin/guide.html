Цены и сроки: короткая инструкция

Актуально для catalog-pricing-7, 29.10.2026.

Как связаны части приложения

Данные квартиры → код определяет состав и объёмы → берёт цены из БД → применяет нужные коэффициенты → сохраняет смету → обновляет план по действию пользователя.

Админка цен: https://mobile-prorab.onrender.com/porabadmin Нормы времени: https://mobile-prorab.onrender.com/porabadmin/time-norms.html

Excel нужен для подготовки данных. Изменение Excel не обновляет рабочую базу. Локальная админка и Render меняют разные базы. Сейчас админка публичная, без авторизации.

Пример: пол комнаты 20 м², класс «Комфорт»

Начальные ставки ламината: работа 341,88 ₽/м², материалы 1516,88 ₽/м². Работа: round(20 × 341,88) = 6838 ₽. Материалы: round(20 × 1516,88 × 1,3) = 39 439 ₽. Пол: 46 277 ₽. Подготовка пола, демонтаж и другие работы считаются отдельно.

Плитка использует собственные цены tile_floor, а не старый множитель ×1,6 к ламинату. Готовые классовые комплекты и прайсы СПб не умножаются на класс повторно.

Как изменить цену

1. Найдите нужный код и проверьте единицу. Цена за упаковку — не цена за м².

2. Сохраните прежние значения для возможного возврата.

3. Нажмите «Изменить». В average.work — только работа, в average.material — только материалы.

4. Для комплексной услуги учитывайте включённый монтаж один раз.

5. Укажите доли категорий. Черновые + работа + остаток чистовых = 100%. Доли делят сумму, а не увеличивают её. Для импортированных ref-материалов начальная черновая доля равна нулю; при необходимости классификацию нужно уточнить.

6. Запишите источник, дату, состав, оговорки «от» и включение доставки/монтажа.

7. Поставьте отметку проверки после сверки и сохраните. Галочка не меняет сумму.

8. Пересчитайте контрольный проект и сравните конкретные строки.

Нельзя заменить цену части комплекта полной ценой: ref.K_cabinets — цена 0,01 трёхметрового комплекта. Для 3 м калькулятор покупает 100 таких единиц. Нельзя менять норму времени на срок всей квартиры: единица — чел.-ч / 100 м² операции.

Удаление используемой строки остановит расчёт, которому она нужна. Неиспользуемые справочные строки на него не влияют. Старые сметы сохранятся. Для восстановления нажмите «Вернуть» и заполните данные. Новый произвольный код требует поддержки в коде.

Как обновить существующий проект

1. Открыть «Уточнить параметры проекта».

2. Нажать «Пересчитать по текущим ценам» и дождаться результата.

3. Сравнить сметы и применить расчёт.

4. В финансовом трекере отдельно обновить план из сметы.

Фактические расходы останутся. Начатый график сам не перестроится. Повышение цены не увеличивает нормативные часы. Если надо изменить срок, нужны нормы времени/состав работ, а не завышение стоимости.

Бюджет и срок

Стоимость = сумма строк. Минимум = стоимость × 0,90, максимум = ×1,15. Бюджет с резервом = округлённый максимум ×1,10, с округлением до рубля. При стоимости 1 млн ₽: 900 тыс. — 1,15 млн; с резервом 1,265 млн.

Часы = объём × норма / 100. Для двух человек по 8 часов дни этапа = ceil(часы / 16 × 7/5). Часть работ пока не имеет норм и использует ориентир этапа; при подготовке добавляется условная пауза 8 дней. Верхний срок = ceil(нижний ×1,2).

Что делать при расхождении

- Неверная цена единицы — править справочник.

- Неверные м²/количество — уточнять обмеры и формулу объёма.

- Лишняя работа — проверять выбор и правило включения.

- Не те категории финансов — проверять доли.

- Старая сумма в проекте — проверить пересчёт, применение и обновление плана.

Не подгоняйте одну общую ставку, чтобы скрыть ошибку в количестве. Камень пока не добавляется поверх кухни с постформингом: нужна цена гарнитура без обычной столешницы или подтверждённый вычет. Подробности: SPB_PRICES.md.
